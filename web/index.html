hevm in the browser

The hevm symbolic EVM, the bitwuzla SMT solver and the Solidity compiler, all compiled to WebAssembly. Your code stays on your machine: only a contract you look up on Sourcify, and a solc version you pick, are downloaded.

Test a contract verified on Sourcify: hevm gets its files and solc version, and a first test of it, for you to add properties to.

Source contracts inheriting Test from hevm/Test.sol are tests; hevm checks their prove_ functions for all inputs, and their invariant_ functions after every sequence of calls
Source hevm checks that A and B behave the same on every call, for all arguments: the same return data or revert, and the same storage writes
