hevm in the browser

The hevm symbolic EVM, the bitwuzla SMT solver and the Solidity compiler, all compiled to WebAssembly. Nothing leaves your machine.

Source contracts inheriting Test from hevm/Test.sol are tests; hevm checks their prove_ functions for all inputs, and their invariant_ functions after every sequence of calls
Source hevm checks that A and B behave the same on every call, for all arguments: the same return data or revert, and the same storage writes

Prove a contract on the Solidity tab, then pick Replay in debugger on a counterexample, or Debug symbolically on any function.
